# Executive Dashboard User Guide

## Purpose

The Executive Dashboard provides management visibility into governance performance and security metrics.

---

## Dashboard Components

### Patch Compliance

Shows organisational patching performance against the target.

### Vulnerability Remediation

Displays remediation rates and trends.

### Security Incidents

Summarises security events during the reporting period.

### Monitoring Coverage

Measures visibility across monitored assets.

### Policy Compliance

Measures governance implementation performance.

---

## Intended Audience

- Security Governance Team
- Information Security Management
- Executive Leadership
- Board Members

---

## Usage

1. Open executive_dashboard.html.
2. Review KPI status indicators.
3. Investigate metrics below target.
4. Prioritise remediation activities.
5. Present findings during governance reviews.

---

## Review Schedule

Dashboard metrics should be reviewed monthly.
