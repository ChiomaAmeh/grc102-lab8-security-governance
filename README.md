# GRC102 Security Governance Laboratory

## Overview

This repository contains the complete submission for the GRC102 Security Governance Laboratory Assessment.

The project simulates governance failures similar to those in the Equifax data breach and demonstrates how to implement and verify governance controls in an isolated, Docker-based environment.

---

## Scenario

A simulated organisation operates:

- Internet-facing Apache Struts application
- Customer data database
- Security monitoring environment

The objective was to identify governance weaknesses, analyze risks, implement governance controls, verify remediation effectiveness, and produce executive security metrics and reports.

---

## Assessment Objectives

### Part 1 - Simulated Environment

- Docker-based governance lab deployment
- Vulnerable web application
- Database server configuration
- Governance automation scripts

### Part 2 - Governance Failure Analysis

- Vulnerability identification
- Governance failure assessment
- Attack simulation
- Equifax breach comparison

### Part 3 - Governance Control Implementation

- Patch-management controls
- Database-security controls
- Network-segmentation controls
- Monitoring controls
- Governance-oversight controls

### Part 4 - Metrics and Executive Reporting

- Governance metrics generation
- Executive dashboard
- Board report
- Security-governance KPI reporting
